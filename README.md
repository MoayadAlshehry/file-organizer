# File Organizer CLI

## Description
CLI file organization utility that categorizes files into folders by extension.

## Features
- Categorizes files into subfolders
- --dry-run mode
- --undo functionality

## Technologies
- Python 3.x (Standard Library)

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/MoayadAlshehry/file-organizer.git
   cd file-organizer
   ```

## Usage
Run the application:
```bash
python main.py /path/to/folder
```
